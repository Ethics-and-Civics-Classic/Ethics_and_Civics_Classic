Hey, listen!

When you write a localization file for Stellaris (or any other Paradox game), the 
'Replace' folder is very special. This folder is pre-programmed to automatically 
REPLACE localization that's already in the engine.

What happens if you put original text in here? Well, nothing. It'll run just fine,
but you'll have a hard time finding it again. What happens if you put text meant to 
replace vanilla files anywhere other than this folder? Bad things. Like crashes to 
desktop after the game loads to 100%. So please, put loc files where they belong. 
Thanks.
    -- the devs of EaC.

P.S. Anything in a file labeled 'localizations_needed.yml' is machine translated. If
you see localization in this file that doesn't (or does) make sense in your language,
feel free to review it, edit it, and then put it in the correct loc file. Your 
contributions make this mod more accessible for people around the world, and we really 
appreciate your hard work!
