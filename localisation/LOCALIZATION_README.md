Hey, listen!
When you write a localization file for Stellaris (or any other Paradox game), the 'Replace' folder is very special. This folder is pre-programmed to automatically *replace* localization that's already in the engine. 

What happens if you put original text in here? Well, nothing. It'll run just fine, but you'll have a hard time finding it again. 

What happens if you put text meant to replace vanilla files anywhere other than this folder? Bad things. Like crashes to desktop after the game loads to 100%. So please, for everyone's sanity, put files where they belong! 

Thanks.
    -- the devs of EaC.
